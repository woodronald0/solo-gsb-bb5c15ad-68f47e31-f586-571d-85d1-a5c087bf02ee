# 平面照片标尺校准 Web 应用

上传一张包含**已知实际宽 × 高矩形参照物**（信用卡、打印矩形、标定框等）的平面照片，
依次标记矩形四角后，系统通过**四点 DLT 单应矩阵**完成透视校准；随后可在照片上
绘制一个或多个闭合多边形（每个外环内还可继续绘制**多个镂空孔洞**），实时得到
**校正后的实际面积与周长**——面积按外环减去全部孔洞，周长包含外环与所有孔洞边界。

- 后端：FastAPI（Python 3.11），NumPy 求解/校验 3×3 单应矩阵
- 前端：原生 HTML / CSS / JavaScript，Canvas 渲染，零构建、零前端框架
- 所有几何点以**原始图像像素坐标**存储，缩放 / 平移 / 拖动顶点不改变测量几何
- 前后端使用同一套数值算法（镜像实现），浏览器实时预览，服务器权威复核

## 一条命令启动

需要 Docker（含 Compose 插件）：

```bash
docker compose up -d --build
```

然后在浏览器打开：

> **http://localhost:8000**

端口：宿主机 **8000** → 容器 8000（在 `docker-compose.yml` 的 `ports` 中可改）。
上传的图片与会话保存在宿主机 `./data` 目录（挂载卷），容器重启后仍然存在。

停止：

```bash
docker compose down
```

## 本地直接运行（不用 Docker）

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

访问 http://localhost:8000 。

## 使用步骤

1. **上传照片**：点击右上角按钮，或将图片拖入页面（EXIF 方向会被自动纠正）。
2. **透视标定**：
   - 在侧栏填入参照物的**实际宽、实际高与单位**（mm / cm / m / in / px）；
   - 按 **左上 → 右上 → 右下 → 左下** 的顺序在图上单击四角（与矩形在照片中
     的实际朝向无关，顺序一致即可）；
   - 角点可随时**拖动微调**，标定实时重新计算，有效时四边形变为绿色。
3. **绘制区域**：切换到“绘制”模式，逐点单击多边形顶点；
   - **双击 / Enter / 点击第一个顶点**闭合；
   - `Esc` 取消当前草稿，`Backspace` 撤销最后一个顶点；
   - 可绘制任意多个多边形。
4. **镂空孔洞**：在第 3 步“测量结果”卡片上点击 **「◔ 挖洞」**，进入该区域的挖洞模式
   （琥珀色草稿），在已闭合的外环内部继续画孔洞：
   - 孔洞必须**完全位于外环内部**，与外环、与其它孔洞之间都**不得相交或相切**
     （共点、共边、边穿过、嵌套包含均视为非法）；
   - 面积 = 外环面积 − 全部孔洞面积；周长 = 外环周长 + 全部孔洞周长；
   - 所有环关系都在**透视校正后的实面坐标**中校验（照片上看似分离，校正后冲突也会被拦截）。
5. **查看与编辑**：
   - 右侧实时显示每个区域的**净面积、总周长**，以及每个孔洞各自的面积 / 周长，
     可切换结果显示单位（mm² / cm² / m² / in² / px²，按长度单位平方自动换算）；
   - “编辑”模式可拖动**外环或任一孔洞**的顶点、拖动整个外环 / 整个孔洞，
     **右键顶点删除**，**右键孔洞内部删除整个孔洞**（也可在卡片上按 ✕）；
   - 拖动时实时重算；若当前状态非法，冲突原因会直接显示在图上横幅与卡片中，
     **不会覆盖服务端最后一次有效结果**——拖回合法状态即恢复并自动保存；
   - 每个区域可重命名、单独删除；“清空区域”一键全部重画。
6. **导出**：点击“导出 JSON”，下载本次全部测量结果（含单应矩阵、图像坐标、
   校正后坐标、外环 / 孔洞面积周长及校验状态）。没有孔洞的旧会话仍可正常打开与导出。

## 什么时候会阻止计算（以及原因）

校准与测量在**前端实时拦截**并由**后端再次权威校验**，错误信息直接显示在界面上：

- 角点重合、三点共线、四点不构成凸四边形（顺序错乱/自交）→
  *“四个角点没有构成凸四边形（顺序错乱或自交），请按 左上→右上→右下→左下 依次点击”*；
- DLT 方程组秩亏损（四点共线等退化情况）→
  *“透视变换不可逆：标定四点共线或构成退化四边形，无法从平面照片恢复唯一映射”*；
- 单应矩阵行列式接近 0，或某点映射到无穷远线（齐次分母 ≈ 0）→
  *“透视矩阵行列式接近 0，变换不可逆……”* / *“……映射时分母接近 0（落在无穷远线上）”*；
- 标定对应残差过大（角点与已知矩形对不上）→
  *“透视校准残差过大……请检查点击顺序”*；
- 多边形顶点重合或**边自交** →
  *“多边形自交（边 i 与边 j 相交），自交多边形没有唯一的面积，请调整顶点”*；
- 多边形顶点经透视变换后落在无穷远线附近 →
  *“多边形顶点 k 的透视分母接近 0……无法计算校正后坐标”*；
- 外环 / 孔洞顶点不足、重合、自交，或面积为 0（近似共线退化）→
  *“孔洞 k 面积为 0（顶点近似共线或退化），请调整顶点”* 等；
- 孔洞与外环相交或相切（含顶点落在外环边界、边共线重叠）→
  *“孔洞 k 与外环相交或相切（孔洞边 b 碰到外环边 a），孔洞必须完全位于外环内部且互不接触”*；
- 孔洞顶点位于外环之外 →
  *“孔洞 k 顶点 v 位于外环之外，孔洞必须完全位于外环内部”*；
- 两个孔洞相交 / 相切 / 嵌套包含 →
  *“孔洞 i 与孔洞 j 相交或相切（……接触），孔洞之间必须完全分离”* /
  *“……孔洞不允许相互包含”*。

拖动外环或孔洞顶点进入非法状态时，前端会以上述信息实时提示但**不发起保存**；
若服务端收到了非法更新（如并发的旧页面），会返回 **HTTP 409** 并保留其最后一次
有效结果，响应体同时给出当前有效结果（`polygon`）与被拒绝候选（`candidate`）。

数值阈值集中在 `backend/app/geometry.py` 与 `frontend/app.js` 顶部的常量中
（重合、共线、主元、残差、行列式、分母、环接触、零面积容差），两处保持一致。

## 导出 JSON 结构

```json
{
  "schema": "photo-ruler/1.1",
  "exported_at": "2026-09-19T08:11:43Z",
  "session_id": "…",
  "image": { "filename": "….jpg", "width": 800, "height": 600 },
  "calibration": {
    "corners": [{ "u": 0, "v": 0 } /* …4 个图像像素角点 */],
    "rect_width": 85.6, "rect_height": 53.98, "unit": "mm",
    "homography_image_to_world": [[/* 3×3 */]],
    "valid": true, "errors": []
  },
  "all_measurements_valid": true,
  "polygons": [
    {
      "name": "带孔零件",
      "image_points": [{ "u": 150, "v": 150 } /* …外环顶点 */],
      "world_points": [{ "x": 7.13, "y": 6.75 } /* …外环校正后坐标 */],
      "area": 333.1895,
      "outer_area": 433.1895,
      "perimeter": 123.285,
      "holes": [
        {
          "id": "hole-…",
          "image_points": [{ "u": 200, "v": 200 } /* …孔洞顶点 */],
          "world_points": [{ "x": 12.3, "y": 11.4 } /* …校正后坐标 */],
          "area": 100.0,
          "perimeter": 40.0
        }
      ],
      "valid": true, "errors": []
    }
  ]
}
```

面积/周长单位为标定所填单位（其平方）。`area` 为**净面积**（外环面积 `outer_area`
减去全部 `holes[].area`）；`perimeter` 为外环与所有孔洞边界长度之和。
`all_measurements_valid=false` 表示标定或至少一个区域无效（孔洞冲突等），
对应条目的 `errors` 给出具体原因。**没有孔洞的旧会话（schema 1.0）仍可正常打开**，
此时 `holes` 为空数组、`area == outer_area`。

## 算法说明

- 设图像点 `p=(u,v,1)`、实面坐标 `X=(x,y,1)`，映射 `X ∼ H p`。
- 4 对点给出 8 个线性方程（DLT），对两组点做各向同性归一化后以 SVD
  （后端 NumPy）/ 完全选主元 Gauss-Jordan（前端，无第三方库）求零向量，
  再反归一化得到 `H`。
- 校验链：点重合 → 凸性（叉积同号）→ 主元/秩 → DLT 残差 →
  `|det H|` → 逐点齐次分母。
- 多边形：各顶点经 `H` 变换到实面后做自交检测（非相邻边跨立试验），
  再以鞋带公式求面积（取绝对值）、边长累加求周长。
- 带孔区域：外环与每个孔洞分别做自交/退化检查后，在实面坐标中用**闭合线段接触试验**
  （跨立试验 + 共线重叠，端点相接也算接触）检查孔洞↔外环、孔洞↔孔洞；再用射线法严格
  判断包含关系（边界单独识别）。面积用带符号鞋带公式：净面积 = |外环| − Σ|孔洞|；
  总周长 = 外环周长 + Σ 孔洞周长。

## API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/sessions` | 创建会话 |
| GET | `/api/sessions/{id}` | 获取会话（标定 + 各多边形测量值） |
| POST | `/api/sessions/{id}/image` | 上传/替换照片（multipart，清空旧几何） |
| PUT | `/api/sessions/{id}/calibration` | 提交四角与实际宽高，返回 H 与全部区域复算结果 |
| POST/PUT/DELETE | `/api/sessions/{id}/polygons[/{pid}]` | 新增 / 更新 / 删除区域；区域体含外环 `points` 与 `holes[]`（每个孔洞有 `id`、`points`）；非法更新返回 **409** 且保留最后一次有效结果；DELETE 集合路径清空 |
| GET | `/api/sessions/{id}/export` | 下载测量 JSON（attachment） |
| GET | `/api/health` | 健康检查（容器 HEALTHCHECK） |
